## 各页面详细对比

### 1. 首页 (pages/home)

| 对比项 | 源项目 | 目标项目 | 差异等级 |
|--------|--------|----------|----------|
| 页面背景 | 黑色全屏 | 黑色全屏 | 无 |
| 视频播放 | Video 组件 | Video 组件 | 无 |
| 顶部工具栏 | 无 | 切换/历史/我的 按钮 | **高** |
| 气泡提示 | FrostedGlassBubble 组件 | 简化 bubble | 中 |
| 操作按钮栏 | 4个动作 + 动态生成 | 4个动作 + 补齐按钮 | 中 |
| 积分 Toast | 有 | 有 | 无 |
| 视频错误处理 | 基础 | 完整覆盖层 | 低 |
| TabBar | custom-tab-bar | native-tab-bar | **高** |

**关键差异说明**：
1. 原生版增加了顶部工具栏，提供快捷导航
2. 原生版增加了"补齐"按钮入口
3. TabBar 图标系统完全不同（Emoji vs PNG）
