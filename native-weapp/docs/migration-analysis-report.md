# Miao 微信小程序迁移差异分析报告

## 项目概述

| 项目 | 路径 | 技术栈 |
|------|------|--------|
| 源项目 (非原生) | `/miao-wechat-mini` | Taro + React + TypeScript |
| 目标项目 (原生) | `/miao-wechat-mini/native-weapp` | 原生微信小程序 |

---

## 一、全局架构差异

### 1.1 项目结构对比

| 维度 | 源项目 (Taro) | 目标项目 (原生) |
|------|---------------|-----------------|
| **框架** | Taro 3.x + React 18 | 原生微信小程序 |
| **语言** | TypeScript | JavaScript |
| **样式** | Less | WXSS (CSS子集) |
| **构建产物** | `dist/` 目录 | `miniprogram/` 目录 |
| **组件系统** | React 组件 | 微信小程序组件 |
| **状态管理** | React Context + 自定义 storage | 原生 Page data |

### 1.2 全局样式变量对比

**源项目 (app.less)**
- 使用 CSS 变量定义主题色
- 通过 Less 的 mixins 复用样式

**目标项目 (app.wxss)**
```css
page {
  --primary: #E89F71;
  --primary-strong: #FF9D76;
  --primary-container: #FDF2E9;
  --on-primary-container: #633E1D;
  --background: #FFF9F5;
  --surface: #FFFFFF;
  /* ... 完整保留源项目设计系统 */
}
```

**差异分析**：
- ✅ 目标项目完整保留了源项目的 CSS 变量设计系统
- ✅ 颜色、间距、圆角、阴影等设计 token 保持一致

## 二、页面级差异分析

### 2.1 首页 (pages/home)

#### UI 设计差异

| 元素 | 源项目 (Taro) | 目标项目 (原生) | 差异说明 |
|------|---------------|-----------------|----------|
| **顶部导航** | 无顶部按钮 | 有"切换/历史/我的"三个工具按钮 | 原生版增加了快捷入口 |
| **视频区域** | 全屏视频 + 占位图 | 全屏视频 + 占位图 + 错误覆盖层 | 原生版增加了错误处理UI |
| **气泡组件** | `FrostedGlassBubble` 组件 | 简化的 `.bubble` 样式 | 玻璃拟态效果简化 |
| **操作栏** | 动态生成的 action chips | 固定的 action chips + "补齐"按钮 | 原生版增加了补齐功能入口 |
| **无猫状态** | 居中显示 | 居中显示 | 完全一致 |

#### 布局差异

**源项目布局结构**：
```jsx
<View className="home-page">
  <View className="video-fullscreen">
    <CatAvatar /> {/* 组件封装 */}
    <Video />
    <FrostedGlassBubble /> {/* 独立组件 */}
  </View>
  {/* 无 TabBar，由 custom-tab-bar 处理 */}
</View>
```

**目标项目布局结构**：
```html
<view class="home-page">
  <view class="topbar"> <!-- 新增 -->
    <button class="tool-button">切换</button>
    <button class="tool-button">历史</button>
    <button class="tool-button">我的</button>
  </view>
  <view class="video-fullscreen">
    <video></video>
    <image class="placeholder-img"></image>
    <view class="video-error-overlay"> <!-- 新增 -->
      <text>视频暂时无法播放</text>
      <button class="retry-btn">重试播放</button>
    </view>
    <view class="bubble">{{bubbleText}}</view> <!-- 简化 -->
  </view>
  <view class="action-bar">
    <button wx:for="{{actionItems}}">...</button>
    <button wx:if="{{canContinueGeneration}}" class="action-chip unlock">补齐</button>
  </view>
  <native-tab-bar active="home" /> <!-- 原生组件 -->
</view>
```

#### 颜色与字体

| 操作按钮背景 | `rgba(255,255,255,0.28)` | `rgba(255,255,255,0.28)` | ✅ 一致 |
| 激活按钮 | `#E89F71` | `#E89F71` | ✅ 一致 |

## 三、组件级差异分析

### 3.1 TabBar 组件

| 维度 | 源项目 (custom-tab-bar) | 目标项目 (native-tab-bar) |
|------|-------------------------|---------------------------|
| **实现方式** | Taro 自定义组件 | 原生自定义组件 |

```javascript
const tabs = [
  { pagePath: '/pages/diary/index', text: '日志', iconKey: 'diary' },
  { pagePath: '/pages/time-letters/index', text: '时光', iconKey: 'timeLetters' },
  { pagePath: '/pages/home/index', text: '首页', iconKey: 'home', center: true },
  { pagePath: '/pages/points/index', text: '积分', iconKey: 'points' },
  { pagePath: '/pages/profile/index', text: 'MIAO', iconKey: 'profile' },
```

**目标项目 TabBar 配置**：
```javascript
// 使用 Emoji 作为图标
tabs: [
  { key: 'diary', label: '日志', icon: '📝', url: '/pages/diary/index' },
  { key: 'timeLetters', label: '时光', icon: '✉️', url: '/pages/time-letters/index' },
```

**差异总结**：
- ❌ 图标系统完全不同（图片 vs Emoji）
- ❌ 视觉风格差异较大
- ✅ 功能逻辑一致
